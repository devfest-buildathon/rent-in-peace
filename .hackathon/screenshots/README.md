# Responsive Breakpoints & Viewport Specifications

The Rent in Peace frontend is optimized and verified across these standard device profiles:

1. **375px (iPhone SE / Standard Mobile):**
   * Fluid padding: 16px screen gutters
   * Action buttons full width (min-height 50px)
   * Cards stack in 1-column layouts with no horizontal scroll
2. **390px (iPhone 12/13/14/15/16 Base Target):**
   * Primary design frame canvas
   * Statusbar: 30px height with standard mobile indicators
   * Fixed bottom navigation tab bar with elevated active indicator
3. **1440px (Desktop Presentation & Prototype Shell):**
   * Interactive desktop workbench showcasing the mobile prototype inside an iPhone frame
   * Left-hand navigation list of all 16 numbered prototype screens
   * Full print view (`@media print`) rendering the contract paper exclusively
